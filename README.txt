PIANO SIGHT READER - FREE IPHONE HOME SCREEN APP

PUBLISH WITH GITHUB PAGES (no Mac required)
1. Sign in or create a free GitHub account at github.com.
2. Create a PUBLIC repository named piano-sight-reader.
3. Use Add file > Upload files and upload ALL FIVE files from this folder to the repository root.
4. Go to Settings > Pages. Under Build and deployment choose Deploy from a branch; select main and /(root); Save.
5. After deployment, visit https://YOUR-USERNAME.github.io/piano-sight-reader/ in iPhone Safari.
6. Safari Share > Add to Home Screen > Add.

The app works offline after its first successful load. No accounts, tracking, ads or payments within the app.
Progress is stored locally on the iPhone. Clearing website data can erase it.
It uses an on-screen keyboard, not microphone or external MIDI input.
